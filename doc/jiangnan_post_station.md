# 城市驿站

入口：驿站分类下的各城市独立任务。新任务默认关闭。采集目标直接在游戏内置顶，无需在脚本 UI 填写资源。

| --- | --- |
| 应天府 | 秦淮河畔、应天城郊、丽娘府宅 |
| 苏州府 | 阊门、七狸山塘、虎丘、桃花坞 |
| 杭州府 | 钱塘门、旧事·白居易、旧事·小蛮、长恨歌、钱塘春行 |

“敬请期待”仅用于识别地图页面，不提供勾选或点击。各城市分别保存粮草阈值、粮草间隔、优先人物、地图勾选和轮换记录，采集与退出逻辑共用。

页面顶部显示可编辑的“下一次运行时间”，可手动指定本次调度时间；正常运行后按粮草恢复间隔更新。下方“计算后的时间间隔”显示粮草量换算结果。

- 粮草阈值默认 3，仅实际储备 **大于 3** 才出发；等于阈值也等待。
- 运行间隔填写恢复的粮草量，1 粮草 = 40 分钟。支持小数，例如 0.5 为 20 分钟，3 为 2 小时。输入后页面立即显示换算结果，保存后同步调度时间。
- 优先队长可逐行填写或用逗号分隔，依次检查第一页六人。优先选择满体力人物；没有可用优先人物时，选满体力且上限最高者。第一页无人满体力时，改选当前体力最多者；并列按页面顺序。不翻到第二页，体力为零或读数无效的人物不选。
- 地图通过“秦淮河畔、应天城郊、丽娘府宅”三个复选框选择，只在勾选地图中按上述顺序循环。只勾一个时循环该地图，全不勾选则本次跳过。确认没有可采集置顶资源的地图会自动取消勾选并保存，之后不再进入；需要时在游戏内置顶资源后手动重新勾选。单项点击或定位失败不会取消地图勾选。轮换位置会保存到配置中。旧版“轮换”自动迁移为全勾选，“仅某地图”自动迁移为只勾该地图。
- 在各地图的“物品搜索”中置顶要采集的物品，卡片右上角有置顶标志。脚本按首页置顶卡片从左到右、从上到下的顺序，点击采集气泡后立即进入下一项，不等待体力扣除或采集动画，反复循环至体力不足。没有标志的物品不会点击。
- 每次进入地图后，首次打开物品搜索时回顶一次，等待列表停稳，自动读取置顶卡片并缓存标签。之后打开搜索直接识别置顶标签，不切到“采集”分类、不翻页、不重复回顶。UI 的“当前地图置顶资源”为自动显示结果，不用填写。
- 列表关闭后的第一帧立即捕获红箭头，以箭头的竖直中心线确定目标横坐标。只在当前箭头尖端下方 **50–300 像素** 区域内分离背景、识别前景，优先选择轮廓中下部的内部位置；点击随机范围也限制在该区域内。前景识别失败时，沿当前箭头中心线点击尖端下方 **140 像素**，不再逐高度试点。连续两帧确认前景或有效箭头后，只点击一次；镜头或横向位置改变后重新确认，兜底高度使用最新帧的箭头尖端。
- 箭头刚消失时，只在镜头未移动、目标无横向位移的条件下短暂复用中心线，并重新识别当前帧的前景，不能复用旧点击点；140 像素兜底必须有当前帧可见箭头。界外或工具栏位置不点击。识别到气泡才确认采集；点击后立即推进资源顺序，下一项开始时检查体力不足弹窗。
- 采集气泡仍被浮动红箭头遮挡时，只对已确认箭头在气泡内部遮挡的像素修正面积和颜色占比，气泡宽高、位置和细尾检查保持有效；检测到气泡后立即确认，不等待箭头消失。日志漏点原图与来源哈希保存在 `dev_tools/fixtures/post_station/bubble_oct23/cases.json`。
- 只有确认找不到或不再置顶的资源才退出本次任务的资源循环。点偏、定位失败等单项操作失败只跳过当前一次，不结束任务，下一轮仍按顺序尝试；点击后资源列表未关闭时，下一项直接复用列表。
- 点到制作面板时，点击面板外关闭，返回地图后继续下一项；下一轮仍按原顺序尝试该资源。不会点击“制作”，也不会因制作面板排除资源或跳过地图。即使整轮都打开制作面板，也继续原有循环；确认体力耗尽后仍按正常流程退出。
- 体力不足后关闭弹窗并退出地图。弹窗即使延迟到等待下一项资源列表时才出现，也立即中断等待并处理。一般回城；下个地图仍为当前地图、粮草严格超过阈值且足够支付界面显示的切换费用时，切换队长继续。不点击任何体力恢复按钮。
- 出现向上飘动的“你无法到达这里”提示时，仅跳过当前这一次，继续下一项；下一轮轮到同一资源时仍会尝试，即使整轮都无法到达也继续按名单循环。提示消失后再开始下一项，避免将上一项的提示误判给新资源。
- 粮草不足、没有可确认的正体力队长或界面不能确认时停止本次操作，记录状态与异常截图，10 分钟后重试。正常结束按所配置的粮草恢复间隔运行。

验证：`toolkit\python.exe -m unittest dev_tools.test_post_station dev_tools.test_post_station_oct21 dev_tools.test_post_station_panel_recovery dev_tools.test_post_station_craft dev_tools.test_post_station_cities dev_tools.test_post_station_foreground dev_tools.test_post_station_bubble_oct23 dev_tools.test_post_station_ocr -q`。

页面模板生成工具为 `dev_tools/build_post_station_assets.py`，运行模板位于 `assets/jiangnan/post_station`。资源前景定位不依赖逐物品实物模板，140 像素偏移仅用于识别失败的兜底。离线回放 `dev_tools/post_station_foreground_lab.py --video <录像路径> --output <输出目录>` 可生成带中心线、识别框和点击点的联系图及 `replay.json`；使用仓库 Python 运行并令仓库根目录位于 `PYTHONPATH`。该工具不会操作模拟器。

2026-10-23 的前景回归来自用户提供的 59.5 秒、1280×720 录像，包含树木、移动野猪、矿石和棉田，以及被箭头遮挡的小目标。原视频哈希、抽帧时间及人工检查的目标范围保存在 `dev_tools/fixtures/post_station/foreground_oct23/cases.json`。这是离线图像定位验证，尚未验证所有地图、资源及游戏内实际命中率。50–300 像素区域内出现其他前景时也可能入选；识别失败时按用户要求使用 140 像素兜底。

定位阶段临时使用 100 毫秒截图间隔，完成或异常退出后恢复原间隔；比 100 毫秒更快的原设置不被放慢。首次捕获箭头的帧直接参加识别，连续两帧满足条件后立即点击，不等待完整的箭头浮动周期。日志 `PostStationTargetReadyMs` 记录从进入定位循环到发出点击前的就绪耗时，包含取帧和确认，不包含物品列表搜索及点击传输。

在限定搜索区域之前，本机 `toolkit/python.exe` 对 12 张原录像样本各测 6 次：前景定位中位数从约 31 毫秒降至 16 毫秒（P95 约 18 毫秒），包含箭头、页面、气泡及不可达提示的检查组合从约 63 毫秒降至 42 毫秒。优化采用等价颜色直方图、平方颜色距离及 OpenCV 气泡掩膜，143 张回放图的前景落点、气泡框、箭头和页面结果逐项一致。数字为离线图像处理耗时，不是模拟器内完整点击延迟。
