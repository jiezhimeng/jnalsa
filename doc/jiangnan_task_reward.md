# 每日任务奖励领取

界面位置：**江南百景图 → 任务奖励领取**，默认启用。更新后需重新启动 Alas 界面和任务进程，以载入新菜单及识别逻辑。

本任务没有固定领取时刻或定时轮询领取周期。其他江南任务运行时复用截图识别严大人头像及任务入口，命中后在当前任务结束时加入调度队列。任务优先级可以在已有的“任务优先级”页面调整。游戏保持打开、调度空闲时也会观察画面；选择“等待时关闭游戏”时不会为领奖额外打开游戏。

领取流程：

1. 复核主界面头像和任务入口，打开任务界面。
2. 点击左上角图书标签，并确认标题为“每日任务”。
3. 识别到红色“一键领取”后点击。
4. 只有识别到实际“收下”按钮才点击；允许没有奖励弹窗。
5. 连续两帧识别到灰色“一键领取”后确认完成，返回主界面。

已经灰色时不重复点击。识别到其他页面、缺少按钮或超时均不会当作领取成功。失败会保存异常截图，并至少间隔 60 秒才允许头像再次触发；这是失败后的检测退避，不是固定领取排期。相同头像持续可见时不会反复入队；头像在明确主界面消失后可以再次触发，“新”标记变为领奖勾选时也能再次触发。

内部使用现有调度器的隐藏休眠值表示“尚未触发”，界面显示“等待严大人头像触发”，不显示虚拟预约日期。用户关闭任务后不会强制启用。
